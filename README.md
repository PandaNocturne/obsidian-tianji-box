# 天机占卜（Obsidian 插件）

本地六爻、八字、塔罗排盘与历史存档。不内置 AI 解读——复制排盘文本后，可自行到任意 AI 服务中分析。

## 功能

- **六爻**：天机起卦 / 铜钱 / 手动，排盘与卦例库
- **八字**：公历/农历生辰排盘，真太阳时，命理库
- **塔罗**：韦特牌组本地缓存，多种牌阵，牌阵库
- **收藏**：历史记录可收藏筛选
- **数据**：本地 SQLite（`sql.js` → `tianji.db`）

## 开发

```bash
npm install
npm run dev
npm run build
```

产物：`main.js`、`manifest.json`、`styles.css`、`sql-wasm.wasm`

## 使用

1. 在 Obsidian **设置 → 社区插件** 中启用「天机占卜」
2. 点击左侧丝带图标或命令「打开天机占卜」
3. 排盘后可复制文本，到外部 AI 解读
